# Orbital Strike (Fabric, Minecraft 26.3)

Команды (нужны права оператора):
- /orbital at ~ ~ ~       — удар в точку
- /orbital on @p          — удар по игроку (позиция фиксируется при вызове)
- /orbital clear          — отменить все

Настройки (время, радиус, урон) — константы вверху OrbitalStrike.java.

Сборка: ./gradlew build  -> build/libs/orbitalstrike-1.0.0.jar
Нужна Java 25.
